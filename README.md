# Z Lift

**Z Lift — دستیار حرفه‌ای تکنسین آسانسور** · Elevator technician assistant PWA

اپلیکیشن ماژولار و کاملاً آفلاین (PWA) برای تکنسین‌های آسانسور: مدیریت پروژه، گزارش سرویس،
چک‌لیست‌های EN 81-20، محاسبات فنی، عیب‌یابی درختی، کدهای خطای درایو، انبار قطعات،
فاکتور و قرارداد، تقویم شمسی سرویس و گزارش ماهانه — به‌علاوه امضای دیجیتال روی گزارش سرویس،
کتابخانهٔ استانداردها (EN 81-20 / 81-50 / 81-28 / 13015)، شمارهٔ سریالی گزارش، تأمین‌کننده و
کد فنی قطعات، ارزش کل انبار و شاخص‌های مالی داشبورد.

> (امروز، آسانسورها، سرویس‌ها، مالی، ابزار فنی، تنظیمات). داشبورد فقط قهرمان پروژه + نیاز به توجه + سرویس‌های اخیر است.
> فاکتور/قرارداد/گزارش پشت خانهٔ مستقل **مالی** مانده‌اند؛ عیب‌یابی/اندازه‌گیری/چک‌لیست/مرجع پشت **ابزار فنی**.

## اجرا

فایل‌ها استاتیک هستند و نیاز به بک‌اند ندارند:

```bash
python3 -m http.server 8080      # سپس http://localhost:8080
```

برای نصب روی گوشی (Add to Home Screen) باید سایت روی HTTPS یا localhost سرو شود
تا Service Worker فعال شود.

- داده‌های ساختاریافته در مرورگرهای پشتیبانی‌شده داخل IndexedDB محلی `zlift-data` ذخیره می‌شوند
  (بدون سرور و بدون ارسال داده). `zlift_db` و mirror پس از مهاجرت به‌عنوان منبع بازیابی دست‌نخورده
  می‌مانند. بار عکس‌ها در `zlift-photos` است؛ در نبود IndexedDB، localStorage به‌صورت fallback
  استفاده می‌شود. تکمیل مهاجرت فقط پس از خواندن مجدد و تطبیق محتوا/تعداد/روابط علامت می‌خورد.
- خروجی JSON پشتیبان همیشه self-contained است (عکس‌ها از IndexedDB دوباره داخل فایل قرار می‌گیرند).
- حساب آزمایشی: `tech / 123456`
- پشتیبان‌گیری: از منوی کناری → آیکن 💾 (**پشتیبان محلی**) — خروجی JSON + بازیابی با تأیید و rollback خودکار.
  توجه: نسخهٔ محلی در برابر گم شدن گوشی/خرابی دستگاه/پاک شدن دادهٔ مرورگر محافظت نمی‌کند؛
  مرتب خروجی JSON بگیرید و جای مطمئن نگه دارید.

## تست

```bash
npm install
npm test
```

تست‌ها فایل واقعی `index.html` را در jsdom بالا می‌آورند، همه مسیرها را رندر می‌کنند،
همه محاسبه‌گرها/فلوهای عیب‌یابی/مقالات دانش را اجرا می‌کنند و رگرسیون‌های شناخته‌شده
(مرزهای روز شمسی، حذف خوش‌بینانه، موجودی انبار در فاکتور، اسکیپ کاراکترها در هندلرها،
قرارداد فعال/منقضی، هم‌زمانی رندر و …) را بررسی می‌کنند. خروجی موفق = `RESULT: n passed, 0 failed`.

## نکته انتشار

هر بار که `index.html` تغییر می‌کند، مقدار `CACHE` در `sw.js` را یک شماره جلو ببرید
(`zlift-pwa-vNN`) تا کاربران نسخه جدید را بگیرند؛ اپ خودش بنر «نسخه جدید آماده است» را نشان می‌دهد.
